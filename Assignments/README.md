# Assignments

This folder contains the five course-outcome assignment submissions for ITA0605 Machine Learning. Each assignment directory includes its notebook or report and, for the later assignments, the supporting source code, data, figures, execution logs, and result files.

## Included assignments

- `CO1-Assignment’ 1`: concept learning, Candidate-Elimination, and ID3 decision-tree work.
- `CO2-Assignment2`: perceptron, neural-network backpropagation, and related experiments.
- `CO3-Assignment3`: question-wise machine-learning calculations, outputs, and visualisations.
- `CO4_Assignment_4`: seven reproducible experiments on instance-based learning, regression, RBF models, case-based reasoning, noise, and feature selection.
- `CO5_Assignment 5`: NumPy and pandas data-processing, analysis, visualisation, and reproducible-pipeline work.
