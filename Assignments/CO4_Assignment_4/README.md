# CO4 Assignment 4

This is a reproducible seven-question machine-learning project. It includes the submitted PDF report, Python implementations, deterministic datasets, execution logs, numeric CSV/JSON results, graphs, diagrams, and dependency metadata.

## Questions

1. k-NN distances and Voronoi analysis.
2. Feature scaling, dimensionality, distance weighting, and k selection.
3. Locally weighted regression.
4. XOR and two-crescent radial-basis-function models.
5. Case-based reasoning and similarity-weight sensitivity.
6. Learning cost, label noise, dataset size, and tree-index behaviour.
7. Training-only feature selection and model redesign.

Run `python -m pip install -r requirements.txt`, then `cd Programs && python run_all.py`. The existing `Outputs/` and `Results/` folders preserve the supplied execution evidence. `Manifest.json` records the expected project artefacts.
