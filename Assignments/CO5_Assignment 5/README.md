# CO5 Assignment 5

This submission demonstrates NumPy and pandas workflows using manufacturing sensor and production data. It includes the report PDF, source programs, raw and cleaned datasets, execution logs, tabular outputs, plots, a redesign diagram, and SHA-256 manifest metadata.

## Questions

- Q1: NumPy sensor arrays and machine-temperature data.
- Q2: statistics, outlier-aware cleaning, and NumPy persistence.
- Q3: pandas inspection and data cleaning.
- Q4: combining, merging, grouping, pivoting, and ranking production data.
- Q5: production visualisation and defect analysis.
- Q6: a reproducible data-processing pipeline and changed-data comparison.
- Q7: pipeline redesign and validation.

Install the packages in `requirements.txt` and run `python run_all.py` from this directory. `MANIFEST_SHA256.txt` can be used to verify the supplied artefacts.
