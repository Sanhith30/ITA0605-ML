# Lab Exercises

This folder contains 20 standalone Jupyter notebooks for the ITA0605 Machine Learning laboratory. The experiments progress from concept learning and classical algorithms to regression, classification, clustering, and applied prediction tasks.

## Experiments

1. FIND-S; 2. Candidate-Elimination; 3. ID3 decision tree; 4. ANN backpropagation; 5. k-NN; 6. Naive Bayes; 7. logistic regression; 8. linear regression; 9. linear versus polynomial regression; 10. EM algorithm; 11. credit-score classification; 12. Iris k-NN; 13. car-price prediction; 14. house-price prediction; 15. Iris Naive Bayes; 16. classifier comparison; 17. mobile-price prediction; 18. Iris perceptron; 19. bank-loan Naive Bayes; 20. future-sales prediction.

Each notebook includes its aim, background, implementation, and displayed results. Run them with a Python 3 Jupyter kernel or open them in Google Colab.
