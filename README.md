# ITA0605 Machine Learning Report

This repository is the complete ITA0605 Machine Learning coursework portfolio. It contains five course-outcome assignments, 20 laboratory experiments, practical-problem notebooks, and a capstone project for intelligent phishing-website detection.

## Repository contents

- [`Assignments/`](Assignments/): CO1 through CO5 assignment submissions, reports, notebooks, programs, datasets, figures, outputs, and result files.
- [`Lab Exercises/`](Lab%20Exercises/): 20 executable Jupyter notebooks covering core machine-learning algorithms and applied prediction problems.
- [`Capstone/`](Capstone/): a full-stack phishing detection platform with FastAPI, React, a Chrome extension, trained models, notebooks, reports, and tests.
- [`Practical_ProblemsML.ipynb`](Practical_ProblemsML.ipynb): standalone FIND-S and Candidate-Elimination practical problems.

## How to use this repository

Open any `.ipynb` file in Jupyter Notebook, JupyterLab, or Google Colab. Assignment 4 and Assignment 5 also include reproducible Python programs with their dependency files and saved outputs. The capstone has its own setup instructions in [`Capstone/README.md`](Capstone/README.md), including manual and Docker-based startup.

The PDF, DOCX, and PPTX-equivalent report materials are supporting submission documents; the notebooks and source programs are the executable implementations behind them. Each directory contains a local README describing its files and purpose.
