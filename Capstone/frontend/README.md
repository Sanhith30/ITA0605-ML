# PhishShield dashboard

React 19 and Vite frontend for the phishing-detection dashboard. It provides the interactive risk view, analytics, extension guidance, privacy/terms pages, and supporting UI components.

## Commands

- `npm install`: install frontend dependencies.
- `npm run dev`: start the development server.
- `npm run build`: create a production build.
- `npm run lint`: run Oxlint.
- `npm run preview`: preview the production build.

The frontend container is defined by `Dockerfile`; Vite configuration is in `vite.config.js`.
